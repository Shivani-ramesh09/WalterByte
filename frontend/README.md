# Amrita Campus Guide

A mobile-first landing page for the Amrita Vishwa Vidyapeetham Coimbatore campus, built with React, Vite, and Tailwind CSS. The campus hero illustration is an editable SVG in `public/campus-outline.svg`.

## Run locally

```sh
npm install
npm run dev
```

The page is designed around a 390px phone viewport and stays centered in a phone-sized frame on wider screens.
